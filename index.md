## 🛠️ How to Use the Tool

### 🎯 Using the GUI (For Most Users)

1.  **Open the program.** You will see a main window with a big button that says "Select Folder" or "Select Files."
2.  **Choose your cards.** You can select a single card file, multiple files, or an entire folder full of cards.
3.  **Pick a mode.** Choose Fast, Balanced, or Quality mode from the dropdown menu.
4.  **Optional: Turn on lossless mode.** If you want zero quality loss, check the box.
5.  **Click "Start".** The tool processes your cards. A progress bar shows you how things are going.
6.  **Done!** Your compressed cards are saved. The original files are kept in a backup folder, just in case.

### ⌨️ Using the CLI (For Advanced Users)

If you are comfortable with the command prompt, you can use the tool like this:

```
koikatsu-card-texture-tool.exe --input "C:\MyCards" --mode balanced --language en
```

Type `koikatsu-card-texture-tool.exe --help` to see all available commands.

## 💡 Frequently Asked Questions

### ❓ Is this tool safe to use?

Yes. The tool is open source, which means anyone can inspect the code. It only works on card files. It does not modify your game or any other files.

### ❓ Will my cards look different after compression?

Usually, you will not notice any difference. The tool is designed to reduce file size while keeping visual quality high. If you are worried, use the **Quality Mode** or **Lossless Mode**.

### ❓ Can I compress all my cards at once?

Absolutely. Just select the folder that contains all your cards. The tool will process every card in that folder.

### ❓ What if I make a mistake?

No problem. The tool creates a backup folder called `backup` next to your original cards. You can always restore the original files from there.

### ❓ Does this tool work on other games?

The tool is specifically designed for Koikatsu and Koikatsu Sunshine card files. It may not work correctly with other games.

### ❓ Is there a Mac or Linux version?

Currently, this tool is made for Windows only. The code is written in C# and uses Windows Forms for the interface.
